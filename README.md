# Privacy-Safe Synthetic Test Data Generator

A full-stack web application for generating privacy-safe synthetic test data for mobile banking applications.

## Problem Statement
QA teams spend more time manually creating valid test data than executing the actual tests. This tool automates the entire process while enforcing privacy, schema, business, referential, and device rules.

## Features
- **Synthetic Generation**: Faker + NumPy distributions for realistic data
- **Business Rules**: Blocked/Closed accounts, Insufficient Funds enforced
- **Device Compatibility**: Android, iPhone, Tablet, iPad — valid OS pairings
- **Privacy Safe**: Zero real PII — all emails, phones, names are synthetic
- **Manual Override** with Auditable Decision Trail
- **Rollback** to any previous version
- **Legacy CSV Migration** with backup preservation
- **Baseline vs Proposed** benchmark comparison
- **Export**: CSV, Excel, JSON

## Technology Stack
- Python 3.11+, Streamlit, SQLite, Pandas, Faker, Pytest, Plotly

## Installation
```bash
cd synthetic-test-data-generator
pip install -r requirements.txt
```

## Running
```bash
streamlit run app.py
```

## Testing
```bash
python -m pytest tests/ -v
```

## Results
- **54/54 tests passing**
- 10,000 scenarios generated in < 10 seconds
- 100% validity on proposed generator vs ~50% on baseline

## Privacy
All data generated by this application is **100% synthetic** and intended only for testing and demonstration purposes.

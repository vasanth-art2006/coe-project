# User Guide

1. **Install Python**: Ensure Python 3.11+ is installed.
2. **Install dependencies**: Run `pip install -r requirements.txt`.
3. **Start application**: Run `streamlit run app.py`.
4. **Generate test data**: Go to the "Generate Test Data" page, select size, and click Generate.
5. **Validate data**: Go to the "Validation" page to review pass/fail status.
6. **Filter scenarios**: Use the "Generated Scenarios" page to view and export data.
7. **Perform manual override**: Go to "Manual Override", select a scenario, modify fields, and provide a reason.
8. **View audit trail**: Go to "Audit Trail" to see who changed what and why.
9. **Roll back**: Go to "Rollback" to revert a scenario to a previous version.
10. **Import legacy data**: Go to "Legacy Migration", upload/use the legacy CSV to map to the new schema.
11. **Run experiment**: Go to "Experiment" to compare the generation algorithm against the baseline.

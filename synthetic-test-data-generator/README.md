# Privacy-Safe Synthetic Test Data Generator

## Problem Statement
QA teams spend significant time manually creating valid test data for mobile banking apps. This tool automates the process while enforcing strict rules.

## Features
- Schema & distribution-aware synthetic generation.
- Strict referential integrity.
- Business rule enforcement.
- Device/OS compatibility checking.
- Zero PII (Privacy Safe).
- Manual override with Audit Trail and Rollback.
- Legacy CSV migration.

## Tech Stack
- Python 3.11+, Streamlit, SQLite, Pandas, Faker, Pytest.

## Installation
```
pip install -r requirements.txt
```

## Running the app
```
streamlit run app.py
```

## Testing
```
pytest
```

## Privacy Considerations
All data generated by this application is synthetic and intended only for testing and demonstration.
